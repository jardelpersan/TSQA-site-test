# TSQA — Soluções e Tintas em Pó

Landing page institucional da **TSQA Soluções e Tintas em Pó**, desenvolvida para apresentar serviços, aplicações de pintura eletrostática industrial e canais de atendimento.

O site prioriza uma navegação simples, visual responsivo e um fluxo direto de solicitação de orçamento pelo WhatsApp.

## Sobre o projeto

A TSQA atua com soluções técnicas em tintas em pó, desenvolvimento de cores, consultoria e suporte a processos industriais. Esta página apresenta a empresa, seus principais diferenciais, serviços e exemplos de aplicações.

## Funcionalidades

- Navegação por seções com rolagem suave;
- Layout responsivo para desktop e dispositivos móveis;
- Menu mobile expansível;
- Seções institucionais: sobre, serviços, galeria e contato;
- Galeria de aplicações industriais;
- Modal para solicitação de orçamento;
- Envio dos dados do formulário diretamente ao WhatsApp;
- Botão flutuante para contato via WhatsApp;
- Animações de entrada com suporte à preferência de redução de movimento.

## Tecnologias

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Google Fonts — Poppins

## Como executar localmente

Como este é um projeto estático, não há dependências para instalar.

1. Clone o repositório:

   ```bash
   git clone https://github.com/jardelpersan/TSQA-site-test.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd TSQA-site-test
   ```

3. Abra o arquivo `index.html` no navegador.

Para uma experiência de desenvolvimento melhor, use uma extensão de servidor local, como o **Live Server** no VS Code.

## Personalização

Os dados de contato e o número de WhatsApp ficam em `index.html` e `js/script.js`. Antes da publicação, confirme que estão atualizados. As imagens de aplicações podem ser substituídas na pasta `img/Produtos/`, preservando ou atualizando os respectivos caminhos no HTML.
